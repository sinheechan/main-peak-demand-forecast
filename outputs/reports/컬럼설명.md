# HIPE 원본 컬럼 설명

- 3상 기기 파일 기준 362개 컬럼 (2상 기기 파일은 114개)
- 상: L1/L2/L3, 선간전압 U = 상과 상 사이, 상전압 V = 상과 중성선 사이
- 접미사 _F: 단위 없는 비율 값

## 저장 컬럼 (1_load_data.py의 KEEP_COLS)

362개 중 12개만 저장한다. 피크 수요 예측과 부하 패턴 분석에 필요한 핵심 물리량만 남기고, 나머지는 중복되거나 계산할 수 있거나 목적과 거리가 먼 값이라 뺐다.

- SensorDateTime : 시계열 기준축 (저장 시 tmp_timestamp + tmp_tzoffset으로 변환)
- P_kW : 실제 소비 전력, 예측 대상
- Q_kvar : 모터·유도성 부하 상태
- S_kVA : 전체 부하 규모 (S² = P² + Q² 관계로 품질 검증에도 사용)
- I1_A, I2_A, I3_A : 기동 전류, 상 불평형, 부하 변화가 가장 먼저 드러나는 신호
- V1_V, V2_V, V3_V : 전원 품질, 전압 강하
- F_Hz : 데이터 품질 확인용 (50Hz에서 크게 벗어나면 센서 문제)
- L_F : 부하 종류와 효율 상태 (역률 = P / S)

### 뺀 컬럼과 이유

| 그룹 | 컬럼 수 | 예시 | 뺀 이유 |
|---|---|---|---|
| 차수별 고조파 | 313 | H03_I1_F ~ H63_V3_F, H_MAX_* | 전력 품질 분석용. 차원만 크게 늘리고 고차 성분은 대부분 0에 가까움 |
| THD | 10 | THD_I1_F 등 | 고조파 요약값. 1차 버전에서는 제외. 중성선 THD는 3상 THD_IN_F, 2상 THD_In_F로 표기가 달라 스키마가 어긋남 |
| 선간전압 | 3 | U12_V, U23_V, U31_V | 상전압 V1~V3과 정보가 겹침 (평형 시 U ≈ √3·V) |
| 상별 전력·역률 | 12 | P1~P3, Q1~Q3, S1~S3, L1~L3_F | 합치면 전체 P, Q, S. 상별 차이는 I1~I3으로 확인 가능 |
| 누적 전력량 | 5 | E_PP_kWh 등 | 계속 증가하는 카운터라 모델 입력으로 바로 쓰기 어려움. 필요하면 P_kW를 적분해 다시 만들 수 있음 |
| 평균값 | 3 | IAVR_A, UAVR_V, VAVR_V | I1~I3, V1~V3에서 바로 계산됨 |
| 중성선 전류 | 1 | IN_A | 1차 버전에서는 제외 (상 불평형 진단 시 후보) |
| 메타 정보 | 3 | Machine, PhaseCount, T_h | Machine, PhaseCount는 파일 안에서 값이 고정(파일명·폴더로 구분). T_h는 계측기 운전 시간이라 기기 상태와 무관 |

### 2상 기기 파일

2상 기기(PickAndPlaceUnit, ScreenPrinter, VacuumPump2) 파일에는 I2_A, I3_A, V2_V, V3_V, L_F가 없다. 1_load_data.py는 파일 헤더에 있는 KEEP_COLS만 읽기 때문에 오류는 나지 않고, 2상 기기 출력 파일에는 해당 컬럼이 아예 빠진다 (NaN으로 채우지 않음). 2상 파일의 역률은 L_F 대신 L1_F에 있다.

### 다시 넣을 만한 컬럼

- THD_I1_F ~ THD_I3_F : 모터·인버터 이상이 전류 왜곡으로 잘 드러남 (고장 진단까지 다룰 경우)
- IN_A : 상 불평형이 생기면 중성선 전류가 올라감
